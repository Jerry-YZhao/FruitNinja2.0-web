# FruitNinja2.0-web

Web port of [FruitNinja2.0](https://github.com/Jerry-YZhao/FruitNinja2.0). Same textures, screens, and rules as the original Python game.

## Run locally

Browsers may block audio if you open `index.html` as a file. From this folder:

```
python3 -m http.server 8000
```

Then open http://localhost:8000
